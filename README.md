# 古典藝術造花｜手作布飾入門

靜態招生型網站，直接開啟 `index.html` 即可預覽，不需要安裝套件。

## 檔案

- `index.html`：課程文案與頁面結構
- `styles.css`：桌面、平板、手機版面
- `photos.js`：作品照片與替代文字對照
- `assets/floral.svg`：裝飾圖與網站圖示（非作品照片）

## 待取得素材

原對話讀取結果沒有附帶照片，專案來源資料夾也是空的。目前照片位置明確標示「作品照片待補」。收到原照片後，將檔案放進 assets，並更新 photos.js 的 src。不可將裝飾圖誤標為學員或老師作品。

## GitHub Pages

把本資料夾的內容上傳至指定 repository 的發布分支根目錄。到 repository 的 Settings → Pages，Source 選 Deploy from a branch，選該分支與 / (root)，儲存後等待部署。所有素材路徑均採相對路徑，適用於 repository 子路徑。
